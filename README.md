# Lab Publications Automation

1. Edit `config.json`.
2. Push this repository to GitHub.
3. Add optional repository secrets.
4. Run the workflow manually once.
5. Enable GitHub Pages from the `main` branch/root.
6. Replace the URL placeholders in `squarespace-code.html`.
7. Paste that file into a Squarespace Code Block.

Sources: PubMed, Crossref, and optionally ORCID.
